# 课题七：Proxy Lab

> 预计耗时：3~6 天

浏览器访问网页时，中间往往还站着一位"中间人"——代理服务器。它替浏览器把请求转给真正的服务器，再把响应转回来；顺手还能缓存一份，下次别人要同一个页面就直接给，不用再跑一趟外网。

这一章你要写一个**带缓存的并发 Web 代理**：既要懂 HTTP 请求/响应长什么样，又要用 socket 跟两边说话（CSAPP 的 `rio` 包会帮你不少忙），最后还要把"多客户端"和"缓存"这两件事做对——并发写缓存是所有踩坑里最经典的一个。

任务来自 CMU 的经典实验 **Proxy Lab**。[在此](https://csapp.cs.cmu.edu/3e/labs.html)下载 README 和 Self-Study Handout 即可。

> 好好读官方 writeup。

学习 CSAPP 第 10 章 **系统级 I/O**、第 11 章 **网络编程**、第 12 章 **并发编程** 并完成 Proxy Lab。
