# 课题五：Cache Lab

> 预计耗时：3~6 天

在一轮的【楔子】里，你见过这样两个程序：做的事情几乎一样，只是把 `i` 和 `j` 对调了一下，跑的耗时却差了四倍多。当时我们只问了一句"为什么"就跳过了，现在我们可以将其作为本题的主角了——**缓存(cache)**。

这一章你不再只是"知道有缓存"，而是要做到两件事：

1. **把缓存本身写出来**。给你一段程序的内存访问序列(trace)，你要写一个通用缓存模拟器 `csim`，按参数模拟指定组相联度的缓存，逐条判断命中、不命中、驱逐，并输出统计结果。
2. **用缓存知识加速矩阵转置**。给一个朴素的矩阵转置函数，你要在保证结果正确的前提下，让它在模拟缓存上的不命中次数尽可能少。

任务来自 CMU 的经典实验 **Cache Lab**，由两部分组成（Part A 写模拟器、Part B 优化转置）。[在此](https://csapp.cs.cmu.edu/3e/labs.html)下载 README 和 Self-Study Handout 即可。

> 好好读官方 writeup。**记分规则、满分线、运行时间限制都以 writeup 的 Evaluation 一节为准**。

## 学习要求

学习 CSAPP 第 6 章 **存储器层次结构** 并完成 Cache Lab。
