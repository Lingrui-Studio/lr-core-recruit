# 内存管理

若是直接推进 CSAPP，大家可能会有点吃不消，于是思来想去，还是先从内存管理开始吧！

程序运行时，代码、变量和临时数据都要放进内存，操作系统也要为每个进程安排和保护这些内存。程序能否正确运行、运行多久、能同时处理多少任务，往往都和它怎样使用内存有关。

本题主要讨论**进程的内存管理**，也即 C 语言程序运行时的内存管理，重点放在内存地址空间、栈和堆、变量的作用域与生命周期、指针，以及动态内存分配。

## 两个例子

请自己运行例 1，观察输出结果；运行例 2，并在任务管理器查看内存用量的变化，然后及时**手动终止**运行中的程序。

- 例 1：局部指针

```c
#include <stdio.h>

// 获取一个字符串
char *get_name(void) {
    char name[] = "Lingrui";
    return name;
}

int main(void) {
    char *name = get_name();
    printf("%s\n", name);
    return 0;
}
```

- 例 2：内存泄露

```c
#include <stdlib.h>
#include <string.h>

int main(void) {
    while (1) {
        char *request = malloc(1024);
        if (request == NULL) {
            return 1;
        }

        strcpy(request, "a request");
        /* 模拟处理 request */
    }
}
```

完成这两个例子之后相信你就能在一定程度上理解内存管理的重要性了。接下来请前往下一个环节学习，最后再返回来解释这两个例子。

## 学习要求

请围绕下面的方向自行查找资料、编写代码运行实验并整理学习笔记，不要求按照固定教材或固定顺序学习。

- **进程的虚拟地址空间**
    - 一个进程为什么拥有自己的地址空间
    - 虚拟地址和物理地址的区别
    - 地址空间各个区域分别有什么用
- **变量的作用域与类型**
    - 变量作用域和生命周期
    - 局部变量、全局变量、静态变量和动态分配对象的区别
- **指针与内存访问**
    - 指针保存的是什么，`&`、`*` 的实际作用和数组变量的本质
    - 指针运算、数组与指针的关系
    - 空指针、野指针、悬空指针、越界访问
- **动态内存管理**
    - `malloc`、`calloc`、`realloc`、`free` 和 `alloca` 的基本用法与区别
    - 重复释放、释放后使用和 `realloc` 失败时的处理
    - 为什么动态内存必须由程序员明确管理
- **数组、字符串与内存布局**
    - C 字符串（字符数组）的长度为什么是实际字符数量+1
    - C 语言中多维数组在内存中的排列方式
- **对象大小与对齐**
    - `sizeof` 的结果与类型、数组、指针的关系
    - 结构体成员的内存布局、填充和对齐
    - 为什么不能用 `sizeof(pointer)` 代替指针所指数组的大小
